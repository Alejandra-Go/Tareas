# 📊 Aplicación de Lista de Tareas + Análisis de Productividad

Esta es una aplicación web interactiva y minimalista diseñada para gestionar pendientes diarios de forma eficiente, desarrollada con tecnologías web modernas y desplegada de forma continua.

## 🚀 Enlace del Proyecto
Puedes ver y probar la aplicación en tiempo real aquí: [https://vercel.app](https://vercel.app)

## 🛠️ Tecnologías Utilizadas
* **HTML5:** Estructura semántica de la interfaz de usuario.
* **CSS3:** Diseño responsivo (Flexbox & Grid), variables globales y una paleta moderna en modo oscuro (*Dark Mode*).
* **JavaScript (Vanilla):** Manipulación dinámica del DOM, gestión de estados y persistencia de datos.

## 📈 Características Destacadas & Análisis de Datos
A diferencia de una lista de tareas convencional, este proyecto incluye un **módulo integrado de análisis de rendimiento** en tiempo real:
* **Métricas Internas:** Procesa y clasifica dinámicamente las tareas activas utilizando métodos analíticos en JavaScript (`filter`, `length`).
* **Indicadores de Rendimiento (KPIs):** Muestra el total de tareas pendientes, completadas y calcula porcentualmente una **Tasa de Productividad** para motivar al usuario.
* **Persistencia:** Almacenamiento local mediante `localStorage` para conservar el historial de rendimiento del usuario incluso al recargar la página.
